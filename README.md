# 🍽️ Restaurant Website

A responsive and visually appealing restaurant website created using **HTML and CSS**. The project provides a complete restaurant browsing experience with dedicated pages for food categories, restaurant information, contact details, banquet services, and user sign-up.

## 🌐 Project Overview

This project is a front-end restaurant website designed to showcase a restaurant's food offerings and services through a simple, attractive, and easy-to-navigate interface.

The website includes multiple sections and dedicated pages for different food categories such as **Breakfast, Snacks, Dinner, and Desserts**, along with restaurant information and contact functionality.

## ✨ Features

* 🏠 **Home Page** — Restaurant landing page with visual branding and navigation.
* 🍳 **Breakfast Menu** — Dedicated page for breakfast items.
* 🍿 **Snacks Menu** — Browse available snacks.
* 🍛 **Dinner Menu** — Explore dinner options.
* 🍰 **Dessert Menu** — Dedicated dessert section.
* 🎉 **Banquet Section** — Information and visuals related to banquet services.
* ℹ️ **About Us** — Information about the restaurant.
* 📞 **Contact Page** — Restaurant contact section.
* 📝 **Sign Up Page** — User registration interface.
* 🔄 **Eat & Repeat** — Additional restaurant/food section.
* 🎨 **Custom Styling** — Individual CSS files are used to style different pages.
* 🖼️ **Images & Media** — Food, restaurant, logo, and background assets are included in the project.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/kumarrouniit/restaurant1.git
```

### 2. Navigate to the Project

```bash
cd restaurant1
```

### 3. Open the Website

Because this is a front-end HTML/CSS project, no backend server or package installation is required.

You can open:

```text
home.html
```

directly in your browser.

Alternatively, if you use **Visual Studio Code**, install the **Live Server** extension and open the project using Live Server.

## 🖥️ Running with VS Code

1. Open the `restaurant1` folder in VS Code.
2. Open `home.html`.
3. Right-click inside the file.
4. Select **Open with Live Server**.
5. The website will open in your browser.
